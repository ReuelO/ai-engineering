# LLM Fundamentals

## What is an LLM?

A Large Language Model (LLM) is an AI model trained on large amounts
of text and other data to generate and transform language.

## What is an API?

An API (Application Programming Interface) allows one software
application to communicate with another according to defined rules.

## What are we doing?

Our Python application sends an input to an LLM through an API and
receives a generated response.

```text
Python application
       |
       | API request
       v
   LLM service
       |
       | response
       v
Python application
```
