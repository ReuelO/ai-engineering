# LLM CLI

A minimal command-line application that sends user input to an
LLM through an API and displays the generated response.

## Purpose

This project introduces the basic architecture of an AI application:

User input → Python → LLM API → AI response

## Technologies

- Python
- OpenAI Python SDK
- python-dotenv

## Running the project

Create a `.env` file:

```env
OPENAI_API_KEY=your_api_key_here
```
